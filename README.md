# idealtype.github.io

Personal website of Sanghyeong Lee, served at <https://idealtype.github.io>.

Built with Jekyll on GitHub Pages, starting from the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme.

## Editing

| What | Where |
|---|---|
| Name, position, links, email | `_config.yml` |
| About text and research interests | `index.html` |
| Education / Experience / Publications | `_data/education.yml`, `_data/experience.yml`, `_data/publications.yml` |
| Page layout | `_layouts/homepage.html`, `_includes/*.html` |
| Styles | `assets/css/site.css` |

## Local preview

```sh
bundle install
bundle exec jekyll serve
```
